# 범위 판정

## 언제 쓰나
1. 살롱 MVP(`꽃사슴`)에 기능을 새로 넣을지 정할 때
2. "이 기능 넣어도 돼?"처럼 기능이 범위 안인지 물을 때

## 무엇을 받나
1. 넣으려는 기능 설명 (하나 또는 여러 개)
2. 지금 연 폴더 맨 위의 `PRD.md` 중 `넣을 기능`, `기능 요구사항`, `비목표`

## 어떤 순서로 하나
- 넘겨받은 것에 확인할 화면 이름이 없으면 만들기 전에 먼저 묻는다.

1. `PRD.md` 의 `넣을 기능`, `기능 요구사항`, `비목표` 를 읽는다.
2. 받은 기능을 하나씩 나눈다.
3. 기능마다 `넣을 기능` / `비목표` / `PRD.md에 없음` 중 하나로 판정한다.
4. 판정의 근거가 된 `PRD.md` 문장을 그대로 옮겨 붙인다. `PRD.md에 없음` 이면 근거 칸에 "해당 문장 없음"이라고 적는다.

## 무엇을 내놓나
3열 표로 내놓는다. 기능 1개당 1줄.

| 요청 기능 | 판정 | 근거 문장 |

- 결과 내용을 지금 연 폴더 맨 위의 scope-next.md 파일로 저장한다. 파일이 이미 있으면 새 내용으로 덮어쓴다
- 같은 폴더의 template.md 양식대로 내놓는다
- 결과 맨 끝에 [프로젝트] 라고 한 줄 적는다

## 지킬 것
- 받은 파일에 없는 내용은 지어내지 않는다.
