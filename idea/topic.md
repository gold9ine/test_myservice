# 확정 주제
한 줄 정의 : 디자이너를 중심으로 한 커리어·포트폴리오·팔로우 기반 미용 지도
- 쓰는 사람1 : 즐겨찾는 디자이너를 잃은 고객
- 쓰는 사람2 : 이직을 앞 둔 디자이너
- 넣을 기능 :
  1. 디자이너 이름을 검색하면 해당 디자이너의 현재 헤어샵이 보인다.
  2. 디자이너가 새 헤어샵 이름과 연락처를 등록하면 예전 고객이 새 소속을 확인할 수 있다.
  3. 디자이너가 헤어샵을 등록하고 다른 디자이너들이 소속 헤어샵으로 사용할 수 있다.
팀이 이해한 말 :
혜빈유 : 디자이너의 커리어 포트폴리오를 확인하고 팔로우하며, 지역별로 원하는 스타일의 디자이너를 찾을 수 있는 지도 기반 서비스.
정이진 : 디자이너들이 포트폴리오를 내서 헤어샵 홍보 서비스

# 발표 화면
1. 디자이너가 지도에서 새로운 헤어샵을 오픈하고 소속을 옮긴다.
2. 새 헤어샵 이름과 연락처를 넣고 등록을 누르면 예전 고객이 디자이너의 새 소속을 확인할 수 있다.
